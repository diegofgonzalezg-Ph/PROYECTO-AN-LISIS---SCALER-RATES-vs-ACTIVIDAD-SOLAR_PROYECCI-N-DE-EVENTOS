Proyecto ANÁLISIS---SCALER-RATES-vs-ACTIVIDAD-SOLAR PROYECCIÓN DE EVENTOS.
Este repositorio contiene un Jupyter Notebook estructurado en dos partes, primero un análisis estadístico de correlación entre los 
registros de Scaler-Rates y número de manchas solares (SSN). La segunda parte consta de un programa de Machine learning con  de predicción 
de eventos Fourbush.

Descripción del Proyecto.
La primera parte del proyecto incluye la implementación y análisis de diversos modelos y técnicas de correlación, tales como:

*Análisis de Series de Tiempo.
*Coeficiente de Pearson y Sperman.
*Análisis de correlación cruzada. 
*Análisis de serie de potencia. 
*Conteo de eventos Fourbush decrease.

Herramientas y Tecnologías
*Python 3.11
*Jupyter Notebook
*Librerías de Análisis de Datos:
*Pandas
*Plotly
*Scikit-learn
*Category Encoders
*SciPy
*NumPy

La segunda parte del proyecto consta de la implementación de programas de (Ml):
*Random Forest
*Red neuronal
*Pronóstico recursivo multi-paso
